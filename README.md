# 小朋友家庭积分 (xiaopengyou-jifen)

纯前端家庭奖惩积分系统，适合手机浏览器使用。

## 特点

- **纯前端**：单个 HTML 文件，无需后端服务器
- **本地存储**：所有数据存储在浏览器 localStorage 中
- **移动优先**：针对手机屏幕优化设计

## 功能

- 登录界面（首次设置家庭密码，支持修改密码）
- 奖励页面：按分类折叠，选择对应分值
- 惩罚页面：按分类折叠，选择对应分值
- 积分商城：兑换商品，自动扣减积分
- 兑换记录：查看历史兑换记录，支持删除
- 管理页面：修正初始积分、修改密码、增删改奖励/惩罚/商城项目

## 积分计算

- 当日积分余额 = 当日奖励加分 + 当日惩罚扣分（可为负）
- 积分总额 = 初始积分 + 每日余额累计 - 已兑换商品消耗

## 部署

已部署到 EdgeOne Pages。
